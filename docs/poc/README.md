# Product Design POC

The POC sequence is feature contract → image review → clickable review → functional implementation.

## Current batch

- `core-v1/`: deterministic, browser-rendered source for Core screens 01–08.
- `core-v1/screens/`: rendered image artifacts used for design review.
- `visual-direction/evidence-workspace-v1.png`: generated visual-direction reference only. Its displayed names, counts and dates are not product data and must not be copied as evidence.

Open `core-v1/index.html` through a local static server and use hashes `#dashboard`, `#suppliers`, `#add`, `#supplier`, `#evidence`, `#inbox`, `#assessment`, and `#score`.
